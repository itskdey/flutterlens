# flutterlens_ui

Reusable Flutter widgets for [FlutterLens](https://github.com/itskdey/flutterlens), including the widget tree, selected-widget inspector, performance view, and runtime diagnostics.

UI widgets depend on typed `flutterlens_core` models. They intentionally do not make VM Service calls.

Most developers should depend on `flutterlens`, not `flutterlens_ui` directly.

The source and contribution instructions live in the [FlutterLens repository](https://github.com/itskdey/flutterlens). Licensed under MIT.
