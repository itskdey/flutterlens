# flutterlens_core

Platform-independent models and interfaces used by [FlutterLens](https://github.com/itskdey/flutterlens), a live Flutter DevTools extension.

This package contains typed widget, layout, connection, diagnostics, and performance contracts. It does not connect to a VM Service or render Flutter widgets.

Most developers should depend on `flutterlens`, not `flutterlens_core` directly.

The source and contribution instructions live in the [FlutterLens repository](https://github.com/itskdey/flutterlens). Licensed under MIT.
